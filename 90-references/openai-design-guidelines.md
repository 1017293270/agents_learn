# OpenAI Design Guidelines

## 来源信息

- 标题：OpenAI Design Guidelines
- 作者或机构：OpenAI

- URL：https://openai.com/brand/

## 一句话结论

OpenAI 的公开设计指南适合作为“清晰、克制、精确、有人味”的 UI 参考，但不能被当作允许复制 OpenAI 品牌资产的授权。

## 核心观点

- OpenAI 的品牌资产属于 OpenAI，第三方使用名称、Logo、ChatGPT、GPT 等标识时必须遵守其指南和使用条款。
- 字标和 Blossom 标志强调留白、比例、清晰层级和不可随意变形。
- OpenAI Sans 的公开描述强调几何精确、功能性、圆润和亲近感之间的平衡。
- 使用 OpenAI 标志时不能暗示背书、赞助或合作关系。
- 如果项目使用 OpenAI API 或模型，可以准确引用具体模型，但不应把模型名放进应用、产品、开发者或公司名称。

## 可引用事实

- OpenAI 官方品牌指南位于 `https://openai.com/brand/`。
- OpenAI 要求 Logo 只在直接关联 OpenAI 服务时使用，并按官方样式和条款使用。
- OpenAI 禁止第三方误导用户，以为存在 OpenAI 背书、赞助或合作关系。
- OpenAI 的字体说明强调技术精确与人文温度的平衡。

## 适用范围

- 为 agents 学习知识库中的 UI 规范提供视觉方向参考。
- 为 AI-native 界面设定克制、清晰、状态可见的设计标准。
- 为涉及 OpenAI API、模型或服务的界面提供品牌使用边界。

## 局限与风险

- 该资料是品牌指南，不是完整产品 UI 组件规范。
- 不能把 OpenAI 的 Logo、字标、Blossom 或相似图形用作本知识库或项目品牌。
- OpenAI 品牌和模型命名规则可能变化，涉及发布或商业用途时需要重新访问官方页面确认。
