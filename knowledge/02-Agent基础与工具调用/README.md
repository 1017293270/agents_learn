# 02 Agent 基础与工具调用

本模块用于整理 agent 的基础结构、工具调用、权限边界、执行流程和安全问题。

本章默认要求：

- 出现缩写时必须写出英文全称、中文含义和初学者解释。
- 工具相关知识必须区分“模型提出调用意图”和“应用侧真实执行”。
- 安全、权限、审计、失败恢复和 eval 不能省略。
- 对当前 API、SDK、MCP 协议行为的具体判断，需要保留来源和访问日期。

## 推荐阅读顺序

1. 先读 `02-Agent基础概念.md`，建立 agent 的整体结构。
2. 再读 `01-Tool-Calling.md`，理解模型如何提出工具调用。
3. 然后读 `03-工具安全与权限.md`，知道为什么工具不能无边界开放。
4. 接着读 `04-MCP与远程工具.md`，理解远程工具和协议化接入。
5. 最后读 `05-Agent评估.md`，建立上线前后的质量检查框架。
