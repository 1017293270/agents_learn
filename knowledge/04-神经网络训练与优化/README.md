# 04 神经网络训练与优化

本模块用于系统学习神经网络训练主线：输入因子如何表示和组合，模型如何前向计算，损失如何衡量错误，梯度如何反向传播，优化器如何更新参数，以及训练执行流程如何稳定运行。

本章默认要求：

- 出现缩写时必须写出英文全称、中文含义和初学者解释。
- 概念必须从直觉、机制、公式含义、例子、失败模式和实践判断一起解释。
- 不把“常用经验”写成永远正确的事实；调参判断必须带前提。
- 框架行为以 PyTorch 官方文档为主；算法定义以教材、论文和官方文档为主。
- 如果涉及具体 API、默认值、硬件执行或框架特性，要保留访问日期和待验证问题。

## 推荐阅读顺序

1. 先读 `01-神经网络基础概念.md`，建立模型结构的直觉。
2. 再读 `02-因子与特征表示.md` 和 `03-因子组合与特征交互.md`，理解输入如何被模型使用。
3. 接着读 `04-前向传播与损失函数.md` 和 `05-反向传播与梯度.md`，打通训练的数学主链路。
4. 然后读 `06-优化器基础.md`、`07-常用优化器对比.md`、`08-学习率与训练稳定性.md`，理解参数如何被更新。
5. 最后读 `09-执行算法与训练流程.md` 和 `10-失败模式与调参判断.md`，把算法落到真实训练流程和诊断方法上。
