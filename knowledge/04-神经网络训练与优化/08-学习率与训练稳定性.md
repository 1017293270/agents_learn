# 学习率与训练稳定性

## 一句话结论

学习率决定每次参数更新迈多大步，是训练稳定性的第一旋钮；scheduler、warmup、weight decay 和 gradient clipping 则是在不同阶段控制速度、泛化和梯度风险的辅助机制。

## 概念定位

- 它是什么：控制训练过程稳定性和泛化的关键超参数与策略。
- 它不是什么：不是优化器之外的装饰项，也不是一套固定万能配置。
- 相邻概念：optimizer、loss curve、gradient norm、regularization、mixed precision。
- 前置知识：优化器、梯度、loss、validation。

初学者可以先记住：

```text
学习率太大：容易炸。
学习率太小：学得慢甚至像没学。
稳定训练 = 合适学习率 + 合适正则 + 监控梯度和验证集。
```

## 缩写全称速查

| 缩写 | 英文全称 | 中文解释 | 初学者理解 |
| --- | --- | --- | --- |
| LR | Learning Rate | 学习率 | 参数每次更新的步长 |
| WD | Weight Decay | 权重衰减 | 让参数不要无限变大的一种正则方式 |
| L2 | L2 Regularization | L2 正则化 | 惩罚参数平方和 |
| AMP | Automatic Mixed Precision | 自动混合精度 | 用不同数值精度加速训练并节省显存 |
| NaN | Not a Number | 非数值 | 数值异常，常见于训练发散 |
| Inf | Infinity | 无穷大 | 数值溢出 |
| EMA | Exponential Moving Average | 指数移动平均 | 平滑历史值 |

Scheduler 不是缩写，指随训练进度调整学习率的调度器。Warmup 也不是缩写，指训练初期从较小学习率逐步升高。

## 核心概念

### 1. Learning rate

学习率控制更新幅度：

```text
参数 = 参数 - lr * 梯度
```

它是最常见也最敏感的超参数。

### 2. Scheduler

学习率调度器会让 lr 随训练进度变化。

常见策略：

| 策略 | 直觉 | 适合 |
| --- | --- | --- |
| Step decay | 每隔一段降低 | 传统训练 |
| Cosine decay | 平滑下降 | 现代深度训练常见 |
| Exponential decay | 指数下降 | 简单稳定 |
| Reduce on plateau | 指标停滞后降低 | 不确定训练长度 |
| One-cycle | 先升后降 | 快速训练探索 |

### 3. Warmup

训练刚开始参数还很随机，过大学习率可能导致不稳定。Warmup 用较小学习率起步，再逐步升到目标值。

Transformer 和大模型训练中 warmup 很常见。

### 4. Weight decay

Weight decay 用来限制参数规模，帮助泛化。

但对 Adam 这类自适应优化器，传统 L2 和真正的 weight decay 并不完全等价。AdamW 的意义就在于 decoupled weight decay。

### 5. Gradient clipping

Gradient clipping 是梯度裁剪。当梯度范数超过阈值时，把它缩小。

常用于：

- RNN。
- Transformer。
- 强化学习。
- 混合精度训练。
- 容易梯度爆炸的任务。

## 机制与原理

一个稳定训练 step 可能是：

```text
optimizer.zero_grad()
loss = model_loss(batch)
loss.backward()
clip_grad_norm_(model.parameters(), max_norm)
optimizer.step()
scheduler.step()
```

如果使用 AMP，还可能加入 gradient scaler。

关键顺序：

- 先 backward 计算梯度。
- 再根据需要 clip 梯度。
- 再 optimizer.step 更新参数。
- scheduler.step 的位置要按框架和调度器要求确认。

## 适用场景

- 所有神经网络训练。
- loss 震荡、NaN、梯度爆炸、训练慢。
- 大模型、Transformer、RNN、推荐模型。
- 需要提升泛化、控制过拟合。

## 不适用场景

- 根因是数据泄露、标签错误或模型代码 bug 时，只调 lr 无法解决。
- 正则过强导致欠拟合，继续加 weight decay 会更差。
- 梯度本身错误，clip 只是掩盖症状。
- 小模型小数据，复杂 scheduler 可能没必要。

## 前提、边界与反例

- 必要前提：loss 和梯度正常，训练/验证集划分正确，监控指标可靠。
- 适用边界：稳定性策略降低风险，不保证最终最优。
- 反例或例外：如果 loss 一开始就是 NaN，应先查输入、loss 和数值范围，而不是调 scheduler。
- 结论可能失效的条件：batch size 改变、优化器改变、混合精度改变、模型规模改变。

## 对比与替代方案

| 问题 | 可能手段 | 注意 |
| --- | --- | --- |
| loss 发散 | 降低 lr、clip gradient、检查数据 | 先查 NaN 来源 |
| loss 降得慢 | 提高 lr、换优化器、改初始化 | 别只看前几步 |
| 过拟合 | weight decay、dropout、数据增强、早停 | 先确认验证集可靠 |
| 欠拟合 | 降低正则、增大模型、训练更久 | 别过早 early stop |
| 后期停滞 | scheduler 降 lr | 可能已到瓶颈 |

## 示例或最小实验

用同一个模型试三个学习率：

```text
lr = 1e-1 -> loss 爆炸或震荡
lr = 1e-3 -> loss 稳定下降
lr = 1e-6 -> loss 几乎不动
```

这个实验能帮助你形成“学习率是步长”的直觉。

## 失败模式与风险

- lr 太大：NaN、Inf、loss 爆炸。
- lr 太小：训练极慢，被误判模型无效。
- warmup 太短：初期不稳定。
- warmup 太长：前期训练浪费。
- weight decay 太大：欠拟合。
- weight decay 太小：过拟合或参数过大。
- clip 阈值太小：模型学不动。
- scheduler 顺序错误：学习率实际曲线不符合预期。

## 常见误区

- 误区：学习率只影响训练速度。
  - 修正：学习率也影响能否收敛和最终泛化。
- 误区：gradient clipping 能解决所有不稳定。
  - 修正：它只是限制梯度过大，不能修复错误数据和 loss。
- 误区：weight decay 越大泛化越好。
  - 修正：过强正则会欠拟合。
- 误区：scheduler 是可有可无的。
  - 修正：大多数认真训练都需要学习率策略。

## 实践判断

- 什么时候先调 lr：loss 不降、震荡、训练慢。
- 什么时候加 warmup：大模型、Transformer、初期 loss 不稳定。
- 什么时候加 clipping：梯度爆炸、RNN/Transformer、混合精度不稳。
- 落地时最先验证什么：记录真实 lr 曲线、gradient norm、train/val loss。
- 可观察指标或检查点：lr、loss、grad norm、weight norm、NaN/Inf count、validation metric。
