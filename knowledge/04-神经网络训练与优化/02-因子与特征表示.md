# 因子与特征表示

## 一句话结论

因子或特征是模型观察世界的入口；神经网络不是直接理解业务概念，而是通过数值、类别、embedding、归一化后的表示来学习输入和目标之间的关系。

## 概念定位

- 它是什么：把原始业务信息转换成模型可计算输入的过程。
- 它不是什么：不是随便把字段塞进模型，也不是越多字段越好。
- 相邻概念：feature engineering、embedding、normalization、categorical feature、continuous feature、data leakage。
- 前置知识：数据表、向量、神经网络基础、训练/验证划分。

初学者可以先记住：

```text
因子是你认为可能影响结果的因素。
特征是把这些因素变成模型能计算的形式。
```

## 缩写全称速查

| 缩写 | 英文全称 | 中文解释 | 初学者理解 |
| --- | --- | --- | --- |
| ML | Machine Learning | 机器学习 | 让模型从数据中学习规律 |
| DL | Deep Learning | 深度学习 | 用多层神经网络学习表示和预测 |
| ID | Identifier | 标识符 | 用户 ID、商品 ID、广告 ID 等离散编号 |
| OHE | One-Hot Encoding | 独热编码 | 用只有一个位置为 1 的向量表示类别 |
| CTR | Click-Through Rate | 点击率 | 展示后被点击的比例，推荐/广告常见目标 |
| CVR | Conversion Rate | 转化率 | 点击或访问后转化的比例 |
| NLP | Natural Language Processing | 自然语言处理 | 处理文本语言任务 |
| PII | Personally Identifiable Information | 个人可识别信息 | 可能识别个人身份的数据，特征使用要谨慎 |

Factor 在本章里按“影响模型预测的因素”理解，不是金融里的因子投资专用含义。Feature 通常译为“特征”，是模型实际使用的输入字段或表示。

## 核心概念

### 1. 连续特征

Continuous feature 指连续数值，例如：

- 年龄。
- 价格。
- 历史点击次数。
- 停留时长。

连续特征常需要：

- 标准化：减均值、除标准差。
- 归一化：缩放到固定范围。
- 截断极端值：防止异常值主导训练。
- 分桶：把连续值转成区间类别。

### 2. 离散特征

Categorical feature 指类别特征，例如：

- 城市。
- 设备类型。
- 商品类目。
- 用户 ID。

常见表示：

| 表示方式 | 说明 | 适合 |
| --- | --- | --- |
| One-hot | 每个类别一个位置 | 类别少 |
| Label encoding | 类别映射成整数 | 树模型较常见，神经网络需谨慎 |
| Embedding | 类别映射成可学习向量 | 类别多、稀疏、高基数特征 |

### 3. Embedding 表示

Embedding 是把离散对象映射成低维连续向量。

例如：

```text
user_id = 1024 -> [0.12, -0.08, 0.33, ...]
item_id = 88   -> [-0.21, 0.45, 0.09, ...]
```

神经网络会在训练中调整这些向量，让相似用户、相似商品或相似词在向量空间里形成有用结构。

### 4. 目标变量

Target 或 label 是模型要预测的东西：

- 是否点击。
- 是否购买。
- 房价。
- 文本类别。
- 下一个 token。

特征和标签必须严格按时间和业务逻辑分开，避免数据泄露。

## 机制与原理

一个推荐模型的输入可能这样处理：

```text
原始字段：
用户 ID、商品 ID、价格、城市、历史点击次数

表示后：
用户 embedding
商品 embedding
价格归一化数值
城市 embedding
历史点击次数 log 变换后数值

拼接：
[user_emb, item_emb, price_norm, city_emb, clicks_log]

送入：
神经网络
```

关键点是：模型真正看到的是拼接后的向量，不是“用户”或“商品”这些业务词。

## 适用场景

- 推荐系统、广告点击率、风控、用户画像、搜索排序。
- 表格数据和深度学习结合。
- 高基数离散特征，例如用户、商品、query、类目。
- 需要把文本、图片、类别、数值统一成向量输入。

## 不适用场景

- 只有少量简单字段，规则或线性模型足够。
- 特征来自未来信息，会造成泄露。
- 特征不可上线获取，训练可用但推理不可用。
- 特征含敏感 PII，合规和隐私未评估。
- 类别 ID 稀疏到大部分样本极少出现，embedding 学不稳。

## 前提、边界与反例

- 必要前提：特征在训练和上线时含义一致，取值分布可监控，标签定义清楚。
- 适用边界：好的特征表示能降低学习难度，但不能弥补错误标签。
- 反例或例外：用户是否有权限访问资源，不应作为神经网络特征让模型猜，而应由规则判断。
- 结论可能失效的条件：分布漂移、特征缺失、离线/在线不一致、数据泄露。

## 对比与替代方案

| 表示方式 | 优势 | 局限 | 适合 |
| --- | --- | --- | --- |
| 原始数值 | 简单 | 尺度差异大 | 已有稳定尺度 |
| 标准化数值 | 更利于优化 | 需要统计量 | 连续特征 |
| One-hot | 清楚、无顺序假设 | 高基数维度爆炸 | 类别少 |
| Embedding | 低维、可学习相似性 | 需要数据学习 | 类别多 |
| 手工交叉 | 可解释 | 需要经验 | 关键业务组合 |
| 自动交互模型 | 能学习复杂组合 | 更难解释和调参 | 推荐/广告/排序 |

## 示例或最小实验

预测点击：

```text
因子：
- 用户年龄
- 用户城市
- 商品类目
- 商品价格
- 历史点击次数

特征表示：
- 年龄：标准化数值
- 城市：embedding
- 商品类目：embedding
- 商品价格：log 后标准化
- 历史点击次数：log(1 + count)
```

为什么价格要 log？

因为价格可能跨度很大，`10` 到 `10000` 直接输入会让数值尺度差异过强。`log` 变换能压缩长尾，让优化更稳定。

## 失败模式与风险

- 数据泄露：用了点击之后才知道的字段预测点击。
- 离线在线不一致：训练特征和线上特征计算方式不同。
- 缺失值处理粗糙：缺失被误当成真实 0。
- 高基数过拟合：用户 ID embedding 记住训练集。
- 稀有类别学不动：冷门商品样本太少。
- 特征尺度失衡：某些数值特征压倒其他特征。
- PII 风险：敏感字段进入模型或日志。

## 常见误区

- 误区：神经网络不需要特征工程。
  - 修正：神经网络能学习表示，但输入质量、归一化和泄露控制仍然关键。
- 误区：字段越多越好。
  - 修正：无关字段会增加噪声、成本和泄露风险。
- 误区：类别 ID 可以直接当数字输入。
  - 修正：ID 数字大小通常没有顺序意义，应使用 one-hot 或 embedding。
- 误区：embedding 维度越大越好。
  - 修正：维度太大更容易过拟合，也增加内存和计算。

## 实践判断

- 什么时候应该重点做特征表示：表格、推荐、广告、搜索排序、风控。
- 什么时候应该谨慎：敏感数据、高基数 ID、时间序列任务、强因果解释要求。
- 落地时最先验证什么：训练/上线特征一致性、缺失率、分布、泄露、标签时间。
- 可观察指标或检查点：feature coverage、missing rate、drift、embedding norm、train/validation gap。
