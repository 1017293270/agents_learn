# 优化器基础

## 一句话结论

优化器负责根据梯度更新模型参数；最基本思想是沿着让损失下降的方向走，但实际训练需要处理噪声、速度、稳定性和泛化之间的权衡。

## 概念定位

- 它是什么：根据梯度和内部状态决定参数更新方式的算法。
- 它不是什么：不是损失函数，也不是自动保证模型变好的按钮。
- 相邻概念：gradient descent、SGD、mini-batch、momentum、learning rate、Adam。
- 前置知识：损失函数、反向传播、梯度、batch。

初学者可以先记住：

```text
梯度告诉你“往哪边会让 loss 变大”。
优化器通常让参数往负梯度方向走，让 loss 下降。
```

## 缩写全称速查

| 缩写 | 英文全称 | 中文解释 | 初学者理解 |
| --- | --- | --- | --- |
| GD | Gradient Descent | 梯度下降 | 用全部数据计算梯度后更新参数 |
| SGD | Stochastic Gradient Descent | 随机梯度下降 | 用单个样本或小批量估计梯度更新参数 |
| MBGD | Mini-Batch Gradient Descent | 小批量梯度下降 | 每次用一个 batch 更新，是深度学习常见做法 |
| LR | Learning Rate | 学习率 | 每次参数更新迈多大步 |
| EMA | Exponential Moving Average | 指数移动平均 | 对历史信息做衰减平均，momentum 和 Adam 都会用到类似思想 |
| API | Application Programming Interface | 应用程序编程接口 | 框架里调用优化器的接口 |

Optimizer 不是缩写，指优化器或优化算法。

## 核心概念

### 1. Gradient Descent

最朴素的梯度下降：

```text
参数 = 参数 - 学习率 * 梯度
```

如果梯度表示 loss 增加最快方向，那么负梯度方向就是局部下降最快方向。

### 2. Batch、mini-batch、stochastic

| 方法 | 每次用多少数据 | 优点 | 缺点 |
| --- | --- | --- | --- |
| Full-batch GD | 全部训练集 | 梯度稳定 | 慢，内存大 |
| SGD | 单个样本 | 更新频繁，省内存 | 噪声大 |
| Mini-batch SGD | 一小批样本 | 速度和稳定性折中 | batch size 要调 |

深度学习中通常说 SGD，多数情况下指 mini-batch SGD。

### 3. Learning rate

学习率太大：

```text
更新步子太大，可能越过低点，loss 震荡或发散。
```

学习率太小：

```text
更新太慢，训练很久 loss 也不怎么降。
```

### 4. Momentum

Momentum 是“动量”。它不是只看当前梯度，而是保留过去更新方向的惯性。

直觉：

```text
如果连续多步都朝同一方向下降，就加速。
如果梯度来回震荡，就平滑掉一部分抖动。
```

## 机制与原理

普通 SGD：

```text
g_t = 当前 batch 的梯度
theta = theta - lr * g_t
```

带 momentum 的 SGD：

```text
v_t = momentum * v_{t-1} + g_t
theta = theta - lr * v_t
```

这里 `v_t` 可以理解为“带惯性的梯度方向”。Momentum 常用于让训练更快、更平滑。

## 适用场景

- 几乎所有神经网络训练。
- 需要建立优化器直觉。
- 图像分类、推荐、表格、语言模型等训练任务。
- 需要和 Adam、AdamW 等优化器对比。

## 不适用场景

- 不需要训练参数的系统。
- 目标不可微且无可用近似。
- 规则、数据库、权限判断等确定性逻辑。
- 训练不稳定但根因是数据或标签问题时，换优化器不一定解决。

## 前提、边界与反例

- 必要前提：有可微损失，参数有梯度，学习率合理。
- 适用边界：优化器只优化训练目标，不保证业务指标或泛化。
- 反例或例外：如果标签错了，优化器越努力越会学错。
- 结论可能失效的条件：学习率不合适、梯度异常、loss 设计错、batch 数据有偏。

## 对比与替代方案

| 优化方式 | 优势 | 局限 | 适合 |
| --- | --- | --- | --- |
| Full-batch GD | 梯度稳定 | 大数据慢 | 小数据、理论理解 |
| SGD | 简单、泛化常不错 | 噪声大，调参需要经验 | 基线、视觉任务 |
| SGD + Momentum | 更平滑、更快 | 仍需调 lr/momentum | 深度网络常用 |
| Adam | 自适应学习率 | 泛化和 weight decay 要谨慎 | NLP、稀疏梯度、快速原型 |
| AdamW | Adam + 解耦权重衰减 | 仍需调 wd 和 lr | Transformer、现代深度模型 |

## 示例或最小实验

假设只有一个参数 `w`：

```text
w = 1.0
gradient = -3.0
learning_rate = 0.1
```

更新：

```text
w_new = 1.0 - 0.1 * (-3.0)
      = 1.3
```

因为梯度是负的，说明增大 `w` 会让 loss 降低，所以参数变大。

## 失败模式与风险

- 学习率太大：loss 爆炸、NaN。
- 学习率太小：训练几乎不动。
- batch 太小：梯度噪声大。
- batch 太大：泛化可能变差，显存压力大。
- momentum 太大：越过最优区域，震荡。
- 梯度异常：优化器按错误梯度更新。
- 只看训练 loss：忽略验证集过拟合。

## 常见误区

- 误区：优化器越新越好。
  - 修正：优化器要看任务、数据、模型和泛化表现。
- 误区：Adam 一定比 SGD 好。
  - 修正：Adam 常收敛快，但某些任务 SGD + momentum 泛化很好。
- 误区：loss 不降就换优化器。
  - 修正：先查数据、标签、学习率、梯度、loss 实现。
- 误区：batch 越大越快越好。
  - 修正：大 batch 需要学习率策略和显存支持，也可能影响泛化。

## 实践判断

- 什么时候先用 SGD：想建立基线、模型较简单、视觉任务、关注泛化。
- 什么时候先用 Adam/AdamW：NLP、Transformer、稀疏特征、快速验证。
- 落地时最先验证什么：学习率范围、loss 是否下降、梯度是否正常、小 batch 能否过拟合。
- 可观察指标或检查点：train loss、validation metric、gradient norm、update norm、lr curve。
