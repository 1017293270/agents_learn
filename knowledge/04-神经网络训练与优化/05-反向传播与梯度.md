# 反向传播与梯度

## 一句话结论

反向传播用链式法则把损失对输出的影响一层层传回每个参数，得到梯度；优化器再根据这些梯度决定参数如何更新。

## 概念定位

- 它是什么：神经网络训练中计算参数梯度的核心算法。
- 它不是什么：不是优化器本身，也不是“模型自己理解错误原因”的解释系统。
- 相邻概念：gradient descent、autograd、computational graph、chain rule、vanishing/exploding gradients。
- 前置知识：前向传播、损失函数、导数、链式法则。

初学者可以先记住：

```text
前向传播：算出错多少。
反向传播：算出每个参数该为这个错误负责多少。
```

## 缩写全称速查

| 缩写 | 英文全称 | 中文解释 | 初学者理解 |
| --- | --- | --- | --- |
| BP | Backpropagation | 反向传播 | 从损失往回计算每个参数的梯度 |
| AD | Automatic Differentiation | 自动微分 | 框架自动根据计算图计算导数 |
| SGD | Stochastic Gradient Descent | 随机梯度下降 | 用小批量样本梯度更新参数的优化方法 |
| DAG | Directed Acyclic Graph | 有向无环图 | 计算图常可看作没有环的依赖图 |
| NaN | Not a Number | 非数值 | 训练数值崩掉时常见异常值 |
| Inf | Infinity | 无穷大 | 梯度或 loss 溢出时可能出现 |

Gradient 是梯度，不是缩写。它表示“如果参数往某个方向变一点，损失会怎样变化”。

## 核心概念

### 1. 导数和梯度

单个变量时叫导数，多参数时叫梯度。梯度告诉我们 loss 对每个参数的敏感程度。

```text
梯度大：这个参数变化会明显影响 loss。
梯度小：这个参数变化对 loss 影响小。
梯度方向：loss 增加最快的方向。
负梯度方向：loss 下降最快的局部方向。
```

### 2. 链式法则

神经网络是多层函数复合：

```text
x -> layer1 -> layer2 -> loss
```

链式法则让我们能计算：

```text
loss 对 layer1 参数的影响
= loss 对 layer2 输出的影响
  * layer2 对 layer1 输出的影响
  * layer1 输出对 layer1 参数的影响
```

### 3. 计算图

Computational graph 记录每一步计算依赖。

PyTorch 中，启用梯度追踪的 tensor 会形成计算图。调用 `backward()` 时，框架沿图反向计算梯度。

### 4. Autograd

Autograd 是 automatic differentiation 的框架实现。它让你不必手写每一层的导数，但你仍然需要理解：

- 哪些 tensor 需要梯度。
- 梯度会累积。
- 什么时候要 `zero_grad()`。
- 哪些操作会断开计算图。
- 哪些数值问题会让梯度变成 NaN。

## 机制与原理

一个训练 step：

```text
1. optimizer.zero_grad()
2. prediction = model(x)
3. loss = loss_fn(prediction, y)
4. loss.backward()
5. optimizer.step()
```

其中：

- `zero_grad()` 清空旧梯度。
- `model(x)` 前向传播。
- `loss_fn` 计算损失。
- `backward()` 反向传播并把梯度存到参数的 `.grad`。
- `step()` 根据梯度更新参数。

为什么要清空梯度？

因为 PyTorch 默认会累积梯度。这对梯度累积训练有用，但普通训练如果忘记清空，会把多个 batch 的梯度混在一起。

## 适用场景

- 几乎所有神经网络监督训练。
- 需要端到端训练的模型。
- 微调、SFT、推荐模型、图像模型、语言模型。
- 需要自定义 loss 或多任务训练。

## 不适用场景

- 不可微操作直接作为训练目标，例如离散采样、排序指标、规则判断。
- 纯推理，不需要更新参数。
- 只做传统规则系统或数据库查询。
- 需要梯度但中间操作断图，必须重新设计可微近似或强化学习方法。

## 前提、边界与反例

- 必要前提：计算路径可微或有可用近似，参数开启梯度追踪，loss 是标量或可约简。
- 适用边界：反向传播计算的是局部梯度，不保证找到全局最优。
- 反例或例外：`argmax` 这类离散操作通常不可导，不能直接让梯度穿过。
- 结论可能失效的条件：梯度消失、梯度爆炸、数值溢出、图被 detach、in-place 操作破坏梯度。

## 对比与替代方案

| 方法 | 说明 | 优势 | 局限 |
| --- | --- | --- | --- |
| 手写导数 | 人工推导梯度 | 可控、适合小模型学习 | 易错，不适合大网络 |
| 自动微分 | 框架根据计算图求导 | 高效、通用 | 仍需理解图和数值问题 |
| 数值差分 | 微小扰动估计梯度 | 可用于检查 | 慢且不精确 |
| 强化学习估计 | 对不可微决策优化 | 可处理离散动作 | 方差大，训练难 |

## 示例或最小实验

单参数模型：

```text
y_pred = w * x
loss = (y_pred - y)^2
```

如果：

```text
x = 2
y = 10
w = 1
```

则：

```text
y_pred = 2
loss = 64
```

模型预测太小。反向传播会得到一个梯度，告诉优化器应该增大 `w`，让下一次预测更接近 10。

## 失败模式与风险

- 忘记 `zero_grad()`：梯度意外累积。
- 忘记 `backward()`：没有梯度。
- 忘记 `step()`：参数不更新。
- 参数被冻结：`requires_grad=False`。
- 断开计算图：使用 `.detach()` 或把 tensor 转成普通数值。
- 梯度消失：深层网络早期层几乎学不到。
- 梯度爆炸：梯度过大，loss 变 NaN。
- in-place 操作：破坏 autograd 需要的中间值。

## 常见误区

- 误区：backward 会直接更新参数。
  - 修正：backward 只计算梯度，optimizer.step 才更新参数。
- 误区：梯度就是错误大小。
  - 修正：梯度是 loss 对参数的变化率，不等于 loss 本身。
- 误区：自动微分意味着不用懂反向传播。
  - 修正：框架能算梯度，但你要能诊断梯度问题。
- 误区：梯度越大越好。
  - 修正：过大可能导致不稳定，过小可能学不动。

## 实践判断

- 什么时候重点检查梯度：loss 不降、NaN、模型不更新、训练极不稳定。
- 什么时候应谨慎：自定义 loss、复杂控制流、detach、混合精度、梯度累积。
- 落地时最先验证什么：参数 `.grad` 是否存在，梯度范数是否合理，一个小 batch 能否过拟合。
- 可观察指标或检查点：gradient norm、NaN/Inf、parameter update norm、train loss curve。
