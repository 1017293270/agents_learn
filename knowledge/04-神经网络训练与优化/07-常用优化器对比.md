# 常用优化器对比

## 一句话结论

优化器没有绝对最优，SGD 偏简单稳健，Adam 偏快速自适应，AdamW 更适合现代深度网络中的权重衰减；选择优化器时要看任务、梯度稀疏性、泛化、训练预算和调参能力。

## 概念定位

- 它是什么：对常见梯度优化算法的机制、优缺点和适用场景比较。
- 它不是什么：不是“哪个优化器永远最好”的排行榜。
- 相邻概念：learning rate、weight decay、momentum、adaptive learning rate、scheduler。
- 前置知识：梯度、SGD、momentum、loss、batch。

初学者可以先记住：

```text
SGD：步子规则简单。
Momentum：带惯性。
Adagrad/RMSProp/Adam：给不同参数自适应调步子。
AdamW：把 Adam 和更合理的 weight decay 组合起来。
```

## 缩写全称速查

| 缩写 | 英文全称 | 中文解释 | 初学者理解 |
| --- | --- | --- | --- |
| SGD | Stochastic Gradient Descent | 随机梯度下降 | 用小批量梯度更新参数 |
| NAG | Nesterov Accelerated Gradient | Nesterov 加速梯度 | 在 momentum 基础上提前看一步 |
| Adagrad | Adaptive Gradient Algorithm | 自适应梯度算法 | 历史梯度大的参数步子变小 |
| RMSProp | Root Mean Square Propagation | 均方根传播 | 用梯度平方的移动平均调整步长 |
| Adam | Adaptive Moment Estimation | 自适应矩估计 | 同时估计梯度一阶矩和二阶矩 |
| AdamW | Adam with Decoupled Weight Decay | 解耦权重衰减的 Adam | 将 weight decay 从 Adam 梯度更新中分离 |
| L2 | L2 Regularization | L2 正则化 | 惩罚参数平方和，限制参数过大 |
| LR | Learning Rate | 学习率 | 参数更新步长 |
| EMA | Exponential Moving Average | 指数移动平均 | 对历史梯度信息做衰减平均 |

Lion 通常指一种用符号更新的优化器名称，不是传统缩写。本章只做定位，不把它当默认推荐。

## 核心概念

### 1. SGD

优点：

- 简单。
- 内存占用低。
- 泛化表现常常不错。

缺点：

- 对学习率敏感。
- 训练可能慢。
- 梯度噪声大。

### 2. Adagrad

Adagrad 会让频繁出现、梯度累计大的参数学习率变小，对稀疏特征有直觉优势。

问题：累计平方梯度不断增加，后期学习率可能过小。

### 3. RMSProp

RMSProp 使用梯度平方的指数移动平均，而不是无止境累计。它缓解了 Adagrad 后期学习率过小的问题。

### 4. Adam

Adam 同时维护：

- 一阶矩：梯度的移动平均，类似 momentum。
- 二阶矩：梯度平方的移动平均，用于自适应缩放。

直觉：

```text
Adam = Momentum 的方向记忆 + RMSProp 的自适应步长
```

### 5. AdamW

AdamW 的关键是 decoupled weight decay，即“解耦权重衰减”。

Adam 中如果把 L2 正则混进梯度，对自适应优化器来说不等价于传统 weight decay。AdamW 将权重衰减作为单独步骤，有助于更清晰地控制正则化。

## 机制与原理

比较不同优化器可以看三个问题：

1. 是否使用历史梯度方向。
2. 是否对不同参数使用不同有效学习率。
3. weight decay 是否和梯度更新解耦。

| 优化器 | 历史方向 | 自适应步长 | 常见特点 |
| --- | --- | --- | --- |
| SGD | 否 | 否 | 简单、慢但稳 |
| SGD + Momentum | 是 | 否 | 更快、更平滑 |
| Adagrad | 否 | 是 | 适合稀疏，但后期可能太慢 |
| RMSProp | 否/弱 | 是 | 平滑二阶信息 |
| Adam | 是 | 是 | 收敛快，常用默认 |
| AdamW | 是 | 是 | Adam + 解耦 weight decay |

## 适用场景

- SGD：视觉任务、简单基线、关注泛化、愿意调学习率。
- Adam：快速原型、NLP、稀疏梯度、训练初期探索。
- AdamW：Transformer、现代深度模型、需要 weight decay 正则。
- Adagrad：高稀疏特征可作为参考。
- RMSProp：历史上常用于 RNN 和非平稳目标，可作为理解 Adam 的前置。

## 不适用场景

- 没有排查数据和 loss 就盲目换优化器。
- 用 AdamW 但不理解 weight decay 和 learning rate。
- 高风险业务只看训练 loss，不做验证集和线上指标。
- 资源受限但选择状态量很大的优化器。

## 前提、边界与反例

- 必要前提：梯度有效，学习率范围合理，loss 设计正确。
- 适用边界：优化器改善训练过程，不修复错误数据和错误目标。
- 反例或例外：如果模型输出和标签错位，换任何优化器都不会真正解决。
- 结论可能失效的条件：batch size、scheduler、weight decay、初始化和数据分布变化。

## 对比与替代方案

| 优化器 | 优势 | 劣势 | 常见起点 |
| --- | --- | --- | --- |
| SGD | 简单、内存低、泛化常好 | 调参慢，收敛慢 | `lr=0.1/0.01` 视任务 |
| SGD + Momentum | 比 SGD 快更平滑 | momentum 需调 | momentum 0.9 常见 |
| Adagrad | 稀疏特征友好 | 学习率可能衰减过度 | 推荐/稀疏可试 |
| RMSProp | 平滑自适应 | 现代默认少于 Adam/AdamW | RNN 历史场景 |
| Adam | 快速、稳健默认 | weight decay 和泛化需注意 | `lr=1e-3` 常见起点 |
| AdamW | 现代深度模型常用 | wd/lr 仍需调 | Transformer 常见 |

这些起点不是规则，只是实验入口。

## 示例或最小实验

同一个模型，比较三组：

```text
1. SGD + Momentum
2. Adam
3. AdamW
```

记录：

- train loss 下降速度。
- validation metric。
- 最终泛化。
- 梯度范数。
- 参数范数。
- 学习率曲线。

如果 Adam 训练 loss 降得最快，但验证集更差，说明“收敛快”和“泛化好”不是同一件事。

## 失败模式与风险

- Adam 学得快但过拟合。
- SGD 学得慢，被误判为无效。
- weight decay 设置过大，模型欠拟合。
- weight decay 设置过小，参数膨胀或泛化差。
- scheduler 和 optimizer 不匹配。
- 混合精度下梯度缩放异常。
- 梯度稀疏任务用不合适的优化器。

## 常见误区

- 误区：AdamW 是 Adam 的简单升级版，永远更好。
  - 修正：AdamW 主要改进 weight decay 处理方式，仍需调参。
- 误区：论文里用什么优化器，我就必须用什么。
  - 修正：论文配置和你的数据、模型、batch、预算可能不同。
- 误区：优化器决定最终一切。
  - 修正：数据、特征、模型结构、loss、学习率通常同样重要。
- 误区：默认参数足够生产。
  - 修正：默认参数只是起点，不能替代验证。

## 实践判断

- 什么时候优先 AdamW：Transformer、embedding 大模型、现代 NLP、需要权重衰减。
- 什么时候优先 SGD + Momentum：视觉模型、强基线、希望更好泛化且愿意调 schedule。
- 什么时候重点看 Adagrad/RMSProp：稀疏特征、理解自适应优化历史、特定旧模型复现。
- 落地时最先验证什么：lr range、weight decay、验证集曲线、参数范数。
- 可观察指标或检查点：train/val loss gap、gradient norm、update ratio、weight norm、metric stability。
