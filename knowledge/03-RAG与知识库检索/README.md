# 03 RAG 与知识库检索

本模块用于系统学习 RAG、embedding、语义搜索、文档切分、索引、重排、引用、失败模式，以及它们和 agent 工作流的关系。

本章默认要求：

- 出现缩写时必须写出英文全称、中文含义和初学者解释。
- 不能把 RAG 简化成“把资料塞给模型”，必须解释检索、排序、上下文构造和引用。
- 必须区分“资料确实支持答案”和“模型看起来答得像真的”。
- 所有涉及当前产品 API、模型、向量数据库能力的判断，都要保留来源和访问日期。
- 重点关注可实现、可验证、可复盘，而不是堆概念。

## 推荐阅读顺序

1. 先读 `01-RAG基础概念.md`，理解 RAG 解决什么问题。
2. 再读 `02-Embedding向量与语义搜索.md`，理解为什么能按语义找资料。
3. 然后读 `03-文档切分与索引.md`，理解资料进入检索系统前要怎么处理。
4. 接着读 `04-RAG问答流程.md`，把完整链路串起来。
5. 再读 `05-RAG失败模式.md`，知道 RAG 为什么会答错。
6. 最后读 `06-RAG与Agent的关系.md`，把 RAG 放回 agent 工作流里。
