## 一句话结论

线性回归和逻辑回归是最重要的基线模型：它们不一定最强，但最容易解释、最容易诊断，也最适合作为初学者理解建模的起点。

## 概念定位

线性回归，英文是 Linear Regression，用来预测连续数值，例如房价、收益率、销售额。

逻辑回归，英文是 Logistic Regression，用来处理分类问题，尤其是二分类，例如是否违约、是否点击、未来收益是否为正。

名字里有“回归”的逻辑回归并不是回归任务模型，而是分类模型。它先计算一个线性分数，再用 sigmoid 函数把分数映射成 0 到 1 之间的概率。

## 核心概念

| 概念 | 解释 |
| --- | --- |
| 系数 | 每个特征对应的权重，表示该特征对预测方向和强度的影响 |
| 截距 | 没有特征贡献时的基础预测值 |
| 线性关系 | 每个特征对结果的贡献按加法叠加 |
| 残差 | 真实值和预测值之间的差 |
| sigmoid | 把任意实数压缩到 0 到 1 的函数 |
| 正则化 | 对模型复杂度加约束，降低过拟合风险 |
| L1 | Least Absolute Shrinkage 风格的绝对值惩罚，可产生稀疏系数 |
| L2 | Ridge 风格的平方惩罚，让系数更平滑 |

## 机制与原理

线性回归的形式可以写成：

```text
y_hat = w1*x1 + w2*x2 + ... + wn*xn + b
```

其中：

- `x1, x2, ...` 是特征。
- `w1, w2, ...` 是模型学到的系数。
- `b` 是截距。
- `y_hat` 是预测值。

逻辑回归先计算同样的线性分数：

```text
z = w1*x1 + w2*x2 + ... + wn*xn + b
```

然后用 sigmoid 转成概率：

```text
p = 1 / (1 + exp(-z))
```

如果 `p > 0.5`，可以预测为正类；如果 `p <= 0.5`，预测为负类。但 0.5 只是默认阈值，真实业务中阈值应根据成本和收益调整。

## 适用场景

线性回归适合：

- 预测连续值。
- 需要强解释性。
- 希望快速建立基线。
- 特征和目标大致呈线性或可通过变换近似线性。

逻辑回归适合：

- 二分类问题。
- 需要概率输出。
- 需要解释每个特征对分类倾向的影响。
- 样本量不大，但希望模型稳定。

金融因子场景中，线性模型常用于：

- 检查因子方向是否符合直觉。
- 做简单多因子组合。
- 作为复杂模型前的可解释基线。
- 判断特征标准化、去极值、中性化之后是否还有预测信号。

## 不适用场景

不适合直接使用线性模型的情况：

- 特征和目标关系强非线性。
- 特征之间存在复杂交互。
- 类别特征很多且编码复杂。
- 异常值严重影响估计。
- 数据分布随时间快速变化，系数不稳定。

但是“不适合直接使用”不等于“没用”。线性模型仍然可以作为基线和诊断工具。

## 前提、边界与反例

线性模型的核心边界是：它默认特征影响可以相加。

例如：

```text
预测收益 = 0.2 * 动量 + 0.1 * 估值 - 0.3 * 波动率
```

这表达的是每个因子单独贡献，然后加起来。但现实中可能存在交互：

```text
低估值因子只在低波动股票里有效。
```

这种关系不是简单加法，线性模型可能捕捉不好，除非你显式加入交互特征。

反例：

- 如果真实规律是 U 型关系，例如过低和过高的波动率都不好，中等波动率最好，普通线性项会表达困难。
- 如果某个异常值极端大，普通最小二乘回归可能被它严重拉偏。

## 对比与替代方案

| 模型 | 优点 | 局限 |
| --- | --- | --- |
| 线性回归 | 简单、可解释、训练快 | 难捕捉非线性和复杂交互 |
| 逻辑回归 | 概率输出、分类基线强 | 决策边界本质仍偏线性 |
| 决策树 | 能捕捉非线性规则 | 单树容易过拟合、不稳定 |
| 随机森林 | 稳定性更好 | 解释不如线性模型直接 |
| GBDT | 表格数据强模型 | 参数多，过拟合和泄露风险仍在 |

## 示例或最小实验

假设你有两个因子：

- `momentum_20d`：过去 20 日动量。
- `volatility_20d`：过去 20 日波动率。

目标是预测未来 5 日收益。

线性回归可以帮助你回答：

```text
未来收益是否大致随动量增加而增加？
未来收益是否大致随波动率增加而下降？
两个因子的方向是否稳定？
```

逻辑回归可以帮助你回答：

```text
这些因子能否提高“未来收益为正”的概率判断？
```

一个最小流程：

```text
1. 对因子做缺失处理、去极值、标准化。
2. 按时间切分训练集和测试集。
3. 训练线性回归预测未来收益。
4. 训练逻辑回归预测未来收益是否为正。
5. 观察系数方向、验证集指标和分组表现。
```

## 失败模式与风险

| 风险 | 解释 |
| --- | --- |
| 多重共线性 | 特征之间高度相关，系数可能不稳定 |
| 异常值敏感 | 极端样本会影响回归系数 |
| 线性假设过强 | 真实关系非线性时表现有限 |
| 阈值误用 | 逻辑回归输出概率，但分类阈值需要根据业务调 |
| 概率未校准 | 输出 0.8 不一定真的代表 80% 发生概率 |
| 标准化缺失 | 不同量纲特征会影响正则化和系数解释 |

## 常见误区

- 误区一：逻辑回归是回归模型。  
  它通常用于分类，输出的是类别概率。

- 误区二：系数大就一定重要。  
  如果特征没有标准化，系数大小不可直接比较。

- 误区三：线性模型太简单，所以不用学。  
  线性模型是判断数据、特征和目标关系的第一把尺子。

- 误区四：正则化会让模型更强。  
  正则化主要是控制复杂度，不保证一定提高分数。

## 实践判断

初学者应把线性模型当作“体检工具”：

- 如果线性基线完全没有信号，先检查标签、特征和验证方式。
- 如果线性模型有稳定信号，再尝试树模型或神经网络更合理。
- 如果复杂模型远超线性模型，要警惕是否有泄露或过拟合。
- 如果系数方向不符合常识，要回到数据定义检查。
