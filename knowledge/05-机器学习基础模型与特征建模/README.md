# 05 机器学习基础模型与特征建模

本章是从“神经网络训练与优化”走向“金融因子分析”的桥梁。

它不急着追复杂模型，而是先建立一套更底层、更稳的建模直觉：一个预测问题如何定义，数据如何变成特征，模型如何学习规律，指标如何判断好坏，验证方式如何避免自欺，解释工具如何帮助你看懂模型到底依赖了什么。

## 学习目标

- 看懂机器学习任务的完整链路：问题定义、数据、特征、模型、验证、解释、上线监控。
- 理解线性模型、树模型、随机森林和梯度提升树这几类常用基础模型。
- 知道分类、回归、排序任务的区别，以及为什么不同任务必须使用不同指标。
- 建立特征工程、数据预处理、交叉验证、时间序列验证和模型选择的基本判断。
- 为后续金融因子分析打基础：因子不是直接“喂给模型就结束”，而是要经过清洗、对齐、检验、解释和稳健性验证。

## 推荐阅读顺序

1. 先读 01，建立完整流程。
2. 再读 02 和 03，理解最基础的两类模型：线性模型和树模型。
3. 读 04，理解为什么表格数据里梯度提升树很常用。
4. 读 05、06、07、08，建立“指标、特征、验证、选择”的严谨性。
5. 最后读 09 和 10，把模型解释和金融应用连起来。

## 本章可靠性说明

本章主要依据 scikit-learn 官方文档、XGBoost 官方文档、LightGBM 官方文档、CatBoost 官方文档，以及随机森林和梯度提升树的经典论文整理。

这些资料能支持模型定义、常见算法机制和评估方法。但金融市场具有非平稳、噪声高、回测容易过拟合等特点，因此本章涉及金融因子的部分默认作为建模方法论和风险提示，不等同于任何投资建议。
