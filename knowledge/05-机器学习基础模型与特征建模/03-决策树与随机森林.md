## 一句话结论

决策树用一连串“如果……那么……”切分数据，随机森林则用很多棵有差异的树投票或平均，以降低单棵树的不稳定和过拟合风险。

## 概念定位

决策树，英文是 Decision Tree，是一种树状模型。它通过不断选择特征和阈值，把样本分到更纯的子区域。

随机森林，英文是 Random Forest，是集成学习的一种。它训练多棵决策树，并让它们共同做预测。

集成学习，英文是 Ensemble Learning，意思是把多个模型组合起来，让整体预测比单个模型更稳定或更强。

## 核心概念

| 概念 | 解释 |
| --- | --- |
| 节点 | 树上的判断点 |
| 根节点 | 第一层判断 |
| 叶子节点 | 最终输出预测的节点 |
| 分裂 | 按某个特征和阈值把样本分成两部分 |
| 信息增益 | 分裂后数据更纯的程度 |
| Gini impurity | 基尼不纯度，分类树常用分裂标准 |
| Entropy | 熵，衡量类别混乱程度 |
| Bagging | Bootstrap Aggregating，通过重采样训练多个模型 |
| Bootstrap | 有放回抽样 |
| Feature randomness | 每次分裂只看部分特征，增加树之间差异 |

## 机制与原理

决策树的思路很像人工规则：

```text
如果 波动率 > 某个阈值：
    进入左分支
否则：
    进入右分支
```

树在训练时会寻找一个分裂，使得分裂后的子节点更“纯”：

- 分类任务中，一个节点里最好大多数样本都属于同一类。
- 回归任务中，一个节点里的标签值最好更接近。

单棵树的问题是：它很容易为了适应训练数据，把规则切得过细。

随机森林的核心改进有两个：

1. 每棵树看到的数据不同：通过 bootstrap 重采样。
2. 每次分裂看到的特征不同：通过随机选择特征子集。

这样每棵树会犯不同的错误，最后通过投票或平均降低方差。

## 适用场景

决策树适合：

- 需要直观规则解释。
- 特征关系可能非线性。
- 希望快速理解数据分裂结构。

随机森林适合：

- 表格数据。
- 非线性关系明显。
- 特征之间存在交互。
- 希望比单棵树更稳定。
- 不想做太多特征缩放。

金融因子中，随机森林可用于初步探索：

- 哪些因子可能有非线性阈值。
- 哪些因子组合可能共同影响标签。
- 单个因子在不同区间是否表现不同。

## 不适用场景

决策树和随机森林不适合：

- 极高维稀疏文本任务，除非做了合适特征处理。
- 需要平滑外推的连续预测。
- 要求极强线性可解释的场景。
- 时间序列验证不严谨的数据。
- 样本极少但特征很多的场景。

树模型通常不擅长外推。例如训练数据里的市盈率范围是 5 到 50，模型很难合理推断市盈率 200 的情况。

## 前提、边界与反例

树模型能捕捉“局部规则”，但也容易把噪声当规则。

反例：

```text
如果某个日期正好市场大涨，树可能学到“某个偶然特征阈值对应上涨”，但这个规律未来不存在。
```

如果没有严格验证，树模型会显得很聪明，因为它能把训练数据切得很细。但这种聪明可能只是记忆。

## 对比与替代方案

| 模型 | 优点 | 局限 |
| --- | --- | --- |
| 决策树 | 直观、非线性、能处理特征交互 | 单树不稳定，容易过拟合 |
| 随机森林 | 比单树稳定，调参相对简单 | 模型较大，解释较间接 |
| GBDT | 通常表格任务表现强 | 对参数、验证和泄露更敏感 |
| 线性模型 | 可解释、稳定、基线好 | 非线性表达能力弱 |

## 示例或最小实验

假设你用三个因子预测未来是否上涨：

- `momentum_20d`
- `volatility_20d`
- `turnover_20d`

单棵决策树可能学到：

```text
如果 momentum_20d > 0.03 且 volatility_20d < 0.02，则上涨概率较高。
```

随机森林会训练很多棵树：

```text
树1：更关注 momentum 和 volatility
树2：更关注 turnover 和 volatility
树3：在另一个样本子集上学习不同阈值
...
最终：多棵树投票
```

最小实验建议：

```text
1. 先训练一棵浅树，限制 max_depth = 3，观察规则是否符合常识。
2. 再训练随机森林，比较验证集分数是否更稳定。
3. 用时间切分验证，不使用随机打散。
4. 检查特征重要性，但不要把它当成因果结论。
```

## 失败模式与风险

| 风险 | 解释 |
| --- | --- |
| 单树过拟合 | 深树能记住训练样本 |
| 分裂偏好 | 某些连续或高基数特征可能更容易被选中 |
| 解释误读 | 特征重要性不是因果影响 |
| 时间泄露 | 随机划分时间数据会抬高结果 |
| 外推能力弱 | 超出训练范围的数据预测不可靠 |
| 类别不平衡 | 多数类可能主导分裂 |

## 常见误区

- 误区一：树模型不需要预处理。  
  树模型通常不需要标准化，但仍需要缺失处理、异常值检查、标签对齐和泄露检查。

- 误区二：随机森林一定不会过拟合。  
  随机森林降低方差，但如果数据泄露或验证错误，仍然会失败。

- 误区三：特征重要性高说明它真实有因果作用。  
  特征重要性只说明模型使用了它，不说明它导致了结果。

## 实践判断

推荐顺序：

1. 先用浅决策树理解规则。
2. 再用随机森林提高稳定性。
3. 如果随机森林有信号，再尝试 GBDT 系列。
4. 如果复杂模型相比线性模型提升巨大，要优先排查泄露。
