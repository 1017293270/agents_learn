## 一句话结论

模型任务先分清分类、回归还是排序，再选指标；指标选错，模型可能“分数很好但完全没用”。

## 概念定位

机器学习任务常见三类：

- 分类，英文 Classification：预测类别。
- 回归，英文 Regression：预测连续数值。
- 排序，英文 Ranking：预测相对顺序。

它们看起来相似，但优化目标不同。

例如预测股票未来表现：

- 分类：未来 5 日是否上涨。
- 回归：未来 5 日收益率是多少。
- 排序：在股票池里谁更值得排前面。

金融因子很多时候更接近排序任务，因为你关心的是“哪些股票相对更好”，而不是精确预测每只股票未来收益数值。

## 核心概念

| 概念 | 解释 |
| --- | --- |
| Accuracy | 准确率，预测对的比例 |
| Precision | 精确率，预测为正的样本中有多少真为正 |
| Recall | 召回率，真实为正的样本中有多少被找出来 |
| F1 | 精确率和召回率的调和平均 |
| ROC-AUC | 衡量二分类排序能力的指标 |
| MSE | 均方误差 |
| RMSE | 均方根误差 |
| MAE | 平均绝对误差 |
| R2 | 决定系数，衡量解释方差比例 |
| NDCG | 归一化折损累计增益，排序常用指标 |
| IC | Information Coefficient，金融因子中常用的预测相关性指标 |

## 机制与原理

### 分类任务

分类任务输出类别或类别概率。

例子：

```text
输入：用户行为、页面信息
输出：是否点击
```

常用指标：

- Accuracy：类别均衡、错误成本接近时可用。
- Precision：更在乎预测为正是否可靠。
- Recall：更在乎不要漏掉正样本。
- F1：同时考虑 precision 和 recall。
- AUC：更关注排序能力，而不是固定阈值。

### 回归任务

回归任务输出连续值。

例子：

```text
输入：房屋面积、位置、楼层
输出：房价
```

常用指标：

- MSE：对大错误惩罚更重。
- RMSE：和标签单位一致，解释更直观。
- MAE：对异常值相对不那么敏感。
- R2：看模型解释了多少变化。

### 排序任务

排序任务关心顺序。

例子：

```text
输入：候选股票因子
输出：股票相对排名
```

常用指标：

- NDCG：推荐和搜索排序常用。
- Spearman correlation：秩相关。
- IC：因子值与未来收益的相关性。
- 分组收益：按预测分位分组，看高分组是否表现更好。

## 适用场景

| 任务 | 适用场景 |
| --- | --- |
| 分类 | 是否发生、是否通过、是否上涨 |
| 回归 | 价格、收益率、销量、耗时 |
| 排序 | 推荐、搜索、候选资产排序、风险优先级排序 |

金融因子分析中：

- 如果你要判断“涨或跌”，可以做分类。
- 如果你要预测“收益率大小”，可以做回归。
- 如果你要选出“相对更好的资产”，排序往往更贴近目标。

## 不适用场景

不要随便套指标：

- 类别极不平衡时，不要只看 Accuracy。
- 存在极端收益时，不要只看 MSE。
- 交易决策目标是排序时，不要只看回归误差。
- 金融策略需要考虑成本时，不要只看预测指标。
- 风控任务中，不要只看平均表现，还要看尾部风险。

## 前提、边界与反例

反例一：类别不平衡。

```text
10000 个样本中，9900 个是负类，100 个是正类。
模型永远预测负类，Accuracy = 99%。
```

这个模型看似很准，但完全找不到正类。

反例二：回归指标和交易目标错位。

```text
模型 RMSE 很低，但无法把未来收益最高的一组排出来。
```

如果你的目标是选股，排序能力可能比点预测误差更重要。

## 对比与替代方案

| 目标 | 不推荐只看 | 更应该补充 |
| --- | --- | --- |
| 二分类 | Accuracy | Precision、Recall、F1、AUC、混淆矩阵 |
| 回归 | 单一 MSE | RMSE、MAE、残差分布、分位误差 |
| 排序 | 回归误差 | NDCG、IC、分组收益、top-k 命中 |
| 金融因子 | 预测分数 | 分层收益、换手、回撤、成本后收益 |

## 示例或最小实验

同一批股票预测未来 5 日收益：

```text
标签 A：未来 5 日收益 > 0
任务：分类
指标：AUC、F1、precision、recall

标签 B：未来 5 日收益率
任务：回归
指标：RMSE、MAE、R2

标签 C：按未来 5 日收益排序
任务：排序
指标：IC、rank IC、分组收益
```

如果你的最终操作是“买入预测分数最高的前 10%”，那么分类或回归指标只是中间参考，分组收益和风险指标更接近真实目标。

## 失败模式与风险

| 风险 | 解释 |
| --- | --- |
| 指标错配 | 模型优化目标和业务目标不一致 |
| 类别不平衡 | Accuracy 掩盖模型无效 |
| 阈值固定 | 固定 0.5 阈值不一定适合业务 |
| 只看均值 | 忽略尾部风险和极端错误 |
| 排序和回归混淆 | 预测值接近不代表排序好 |
| 离线线上不一致 | 离线指标无法反映真实使用成本 |

## 常见误区

- 误区一：AUC 高就一定赚钱。  
  AUC 只说明排序能力，不包含交易成本、仓位约束、回撤和市场冲击。

- 误区二：RMSE 低就是好模型。  
  如果业务只关心前 10% 样本，整体误差低未必有用。

- 误区三：一个指标足够评价模型。  
  实践中通常需要主指标、辅助指标和风险指标。

## 实践判断

先写下这句话：

```text
这个模型最终要帮助我做什么决策？
```

然后倒推指标：

- 要不要找出少数高价值样本？看 precision、top-k、排序指标。
- 要不要避免漏掉风险？看 recall、尾部损失。
- 要不要预测数值？看回归误差和残差分布。
- 要不要做资产选择？看 IC、rank IC、分层收益和成本后表现。

## 来源与证据

- scikit-learn model evaluation 文档支持分类、回归、多种指标及其适用方式。
- 排序和金融指标部分属于应用扩展；本节把它作为任务定义与指标选择框架，真实投资有效性需要后续实验验证。

## 待验证问题

- 后续金融因子学习中，主要目标是分类、回归还是排序？
- 是否需要把交易成本、换手率和回撤纳入主指标？
- 是否需要区分截面 IC 和时间序列预测误差？
- 指标是否应按行业、市值分组分别评估？
