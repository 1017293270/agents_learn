# 01 大模型的使用与训练

本模块用于整理大模型从基础概念、Prompt 使用，到推理部署、SFT、RLHF 和模型对比的学习内容。

## 小节目录

| 小节 | 文件 | 状态 | 说明 |
| --- | --- | --- | --- |
| 01 | `01-大模型基础概念.md` | 已创建 | 大模型定义、分类、Transformer、训练链路和学习路线 |
| 02 | `02-Prompt工程.md` | 已创建 | Prompt 的组成、写法、技巧、误区和练习 |
| 03 | `03-模型推理与部署.md` | 已创建 | 推理流程、部署方式、延迟、成本、服务优化 |
| 04 | `04-SFT监督微调.md` | 已创建 | 监督微调的目标、数据、流程和风险 |
| 05 | `05-RLHF人类反馈强化学习.md` | 已创建 | RLHF 的动机、流程、奖励模型和边界 |
| 06 | `06-常用大模型对比.md` | 已创建 | 常见模型家族、选型维度、适用场景对比 |

## 学习顺序

建议按顺序读：

1. `01-大模型基础概念.md`
2. `02-Prompt工程.md`
3. `03-模型推理与部署.md`
4. `04-SFT监督微调.md`
5. `05-RLHF人类反馈强化学习.md`
6. `06-常用大模型对比.md`

这条路线先讲清楚“模型是什么”和“怎么使用”，再进入“怎么部署”和“怎么训练/对齐”，最后学习模型选型。

## 本模块质检重点

- 先讲清楚概念，再讲工程细节。
- 不把产品名、模型名和模型类型混为一谈。
- 训练、微调、部署相关内容必须写清楚前提和成本。
- 涉及具体模型能力、价格、上下文长度或 API 行为时，要查最新官方资料。
